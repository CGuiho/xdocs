# Internal records

The complete internal lifecycle records for this project — plans, question
ledgers, review handoffs, validation evidence and the completed-task archive —
live in the private GUIHO repository `CGuiho/guiho`, under `docs/projects/xdocs/`.

Agents working on this project must read them there; they are not duplicated
here because this repository is public.

| Record | Location in `CGuiho/guiho` |
| --- | --- |
| Implementation plans and worker handoffs | `docs/projects/xdocs/plans/` |
| DND question ledgers | `docs/projects/xdocs/questions/` |
| Review handoffs and human reviews | `docs/projects/xdocs/reviews/` |
| Validation evidence | `docs/projects/xdocs/validation/` |
| Completed-task archive | `docs/projects/xdocs/todo/done/` |

What remains in this repository is user-facing: the architecture, decision and
migration documentation, the changelog and the task mirror
[`TODO.md`](../TODO.md). The task list itself stays authoritative in the bound
GitHub Project; `TODO.md` mirrors it.
